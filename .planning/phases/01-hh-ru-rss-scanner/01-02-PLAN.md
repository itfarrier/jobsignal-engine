<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hh.ru RSS → n8n | Untrusted external XML/HTML in descriptions |
| Build Feed List → RSS URL | User Query String becomes URL query param |
| n8n → Airtable | PAT writes Pipeline records |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Tampering | RSS description HTML | mitigate | stripHtml before Airtable; truncate jobDescription to 50k; no eval/innerHTML |
| T-01-05 | Spoofing | SSRF via malicious feed URL | mitigate | Build Feed List constructs URLs only from `https://hh.ru/search/vacancy/rss` template + encodeURIComponent(text) + whitelisted area IDs {1,2,113} — never user-supplied full URL |
| T-01-06 | Tampering | Airtable formula injection | mitigate | Fixed filterByFormula string; user Query String only passed through encodeURIComponent into `text=` param |
| T-01-07 | Denial of service | hh.ru rate limiting | mitigate | Wait 1s between feeds (D-19); max ~8 auto + manual queries per run |
| T-01-08 | Elevation | Safety brake bypass | mitigate | Copy 01d 100 net-new cap in Deduplicate vs Pipeline |
| T-01-09 | Information disclosure | n8n execution logs | accept | Job titles in logs — same as existing scanners |
| T-01-SC | Tampering | npm/pip/cargo installs | accept | No new packages; fixture script uses node builtins only |
</threat_model>
